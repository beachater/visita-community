# Mobile walkthrough concepts

Open `mobile-options.html` directly in a browser, or from the repository root run:

```powershell
python -m http.server 4323 --directory design/walkthrough
```

Then visit <http://localhost:4323/mobile-options.html>. The default D option combines the bottom peek with the minimal overlay: a slim cafe card sits below the movement controls, while close, save, and share stay in a small top row. Switch to A (minimal overlay), B (larger bottom peek), or C (collapsible top) to compare. Each option shares the same illustrative cafe scene and simulated Safari chrome so the amount of blocked room is comparable. The buttons, details sheet, and sample movement controls are interactive. This is a design mock; it does not use a real venue scan, account, or API.

The scene in `cafe-scene.png` was generated for this comparison with the built-in image generation tool. Prompt: “A portrait, first-person view inside a small warm Cagayan de Oro cafe, with a wooden table and upholstered bench, deep green wall, warm plaster and stone, plants and natural afternoon light; realistic room textures and a subtle photogrammetry-preview softness; no people, logos, signs, text, phone frame, or UI.”
