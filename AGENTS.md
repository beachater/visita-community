## Response Formatting

- Make responses visually scannable and concise.
- Start with a brief outcome or summary.
- Organize longer answers under short, bold section headings.
- Use meaningful whitespace between sections.
- Prefer short bullet lists over dense paragraphs.
- Use tables only when they improve comparisons.
- Use fenced code blocks with language identifiers for code.
- Separate completed work, remaining issues, and next steps.
- Mark important outcomes with simple indicators like ✓, !, or → when useful.
- Avoid repeating information or generating large walls of text.
- For project assessments, start with a summary, then show status, risks, and prioritized next actions.
- Keep output compatible with normal terminal Markdown rendering.
